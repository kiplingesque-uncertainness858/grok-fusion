## 📝 Common tasks

### Starting a new build
Open the main dashboard and click Create New Project. Define your goals in the prompt box. The AI creates a file structure and prepares the base code for you.

### Debugging code
If your program shows errors, import your main project folder into the app. Click Analyze Current Project. The tool highlights problem areas and suggests a fix. Review the suggestion and click Apply if you like the proposed code.

### Managing large projects
If a task takes a long time, the tool saves your state automatically. You can close the program and return later. When you reopen the app, it asks if you want to resume your last session.

Only the metadata and code structure reach the processing servers to ensure the AI understands the context of your request. We do not store your private keys or personal identification data.

## ❓ Troubleshooting

If you encounter issues, read these common solutions first:

- **Program does not launch**: Check if your antivirus software flagged the file. Sometimes strict security settings block new installations. Add the app to your allow-list.
- **AI responses are slow**: This usually happens due to heavy internet traffic. Check your connection or restart the app to reset the link to our servers.
- **The tool cannot find my code**: Verify that you are pointing to the root folder of your project and not a sub-folder.
- **Authentication errors**: If you require a login, ensure your credentials match the ones you set during your first sign-up.
